# 📋 Task Management System (Role-Based)

A full-stack task management app with role-based access control supporting **Admin**, **Manager**, and **Team Member** roles. Built with React, Node.js, Express, and NoSQL database.

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React, Tailwind CSS |
| Backend | Node.js, Express |
| Database | MongoDb |

## ⚙️ Setup
```bash
git clone <repository-link>
npm install
npm start
```

## 👥 Roles
- **Admin** – Manage users, create projects, assign managers, view hierarchy
- **Manager** – Dashboard metrics, create/assign tasks, Kanban board
- **Team Member** – View tasks, time tracking, update status, add notes

## ✅ Task Status Flow
`To Do` → `In Progress` → `Review` → `Completed`

## 🎯 Objective
Role-based system design · Team & project management · Task & time tracking · Real-world workflow
